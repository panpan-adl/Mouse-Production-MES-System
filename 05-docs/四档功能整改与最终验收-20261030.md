## 本轮修复与完善

| 内容 | 最终行为 |
| --- | --- |
| 库位删除 | 未使用库位可删除；有库存、单据或历史流水引用时拒绝删除；基础配置与实际仓储库位按仓库和编码同步，不混用两套主键 |
| 库位启停 | 基础配置新增启用／停用；旧接口更新状态也同步到基础配置；停用库位移出业务候选列表 |
| 执行前再次校验 | 草稿确认后库位被停用，过账仍会被拦截；校验失败不新增库存流水，重新启用后可继续处理原单 |
| 整月库存盘点 | 新建物料在建档事务中记录真实的零库存起点及流水水位；期间余额从该起点或可信基线核算。新建12种验收原料可核实整月期初、入、出、期末 |
| 历史依据保护 | 不修改或倒填原有库存基线；已有库存或流水不能被登记为空库存起点；缺失历史的导入物料仍明确显示无法核实 |
| 自然语言理解 | 补充盘点、结存、余额、上月、中文月份、中文日范围、最近若干天等表达；修复“物料名的出入库”后缀、长短名称重叠、仓库名误作类别／产品，以及未知物料被误当成全部库存的问题 |
| 人工复核 | 在现有Skill业务智能体和库存追溯页面内提供条件核对面板，不重新增加独立的“智能业务查询”菜单；可按同物料、仓库、日期核对结果和来源批次 |
| 设备状态图 | 看板增加设备状态分布及明细，读取设备台账和未结束维修单；支持车间筛选，随看板自动刷新；明确不是传感器在线率 |
| 优化前后对比 | 增加真实人工建待办路径：选工序→开始核对→确认创建；自动路径由完整报工后后台生成。展示来源单据和真实时间戳，不填固定效果数字 |
| 人工／自动区分 | 待办列表显示生成方式；人工记录不冒充自动生成耗时。对比说明接口回归样本和页面操作样本不代表真人平均速度 |
| 自动化页面结构 | 将对比流程前置；周期保养清单可展开，避免长日志、长保养清单挡住主要处理入口 |

### 第二档 生产仓储闭环

1. 采购审批后分批收货、来料检验、原料入库，采购累计收货状态联动。
2. 工单领料使原料仓减少、线边库增加，工单子台账与实际库存一致。
3. 排产、开工和分次报工，按工序扣料；关键检验放行后形成可入库成品，进度随事实更新。
4. 分批成品入库使线边库存减少、成品仓增加，不重复计算产量。
5. 销售订单关联分批出货，独立出货检验后扣库存，能够追溯采购、领料、制造、检验及发货。

五项核心链路均通过。另验证重复执行、并发退货、超量、无检验、错误模板、未领料开工、余料退回再领、不良返工、报废及已过账凭据保护。测试使用实际接口和台账核对，不靠修改数据库业务状态冒充完成。

### 第四档 可视化与自动化

- 工单状态、库存水位、设备状态、产量趋势等主题均有真实业务数据；另有质量及齐套视图。
- 小时放行量与真实检验记录直接统计一致，设备数量与设备表一致。
- 已实际验证定时刷新：修改隔离设备状态后，不点击刷新，页面从可用13台变为可用12台、待处理1台；验证后恢复设备状态。
- 人工路径通过界面完成真实待办创建，单次页面操作记录为18.5058秒，随后独立检验放行并关闭待办。
- 自动路径在完整报工后由后台生成待办，没有人工点击队列处理；重复触发不重复生成，独立检验后待办关闭。
- 改进价值为减少人工寻找工序、重复确认来源及创建待办的交互和遗漏；两种计时起点不同，不据此宣称产线效率提升百分比。接口回归操作速度也不解释为真人平均速度。
