# MouseMES 界面改版

采用深蓝导航、浅灰画布、白色卡片与蓝色操作强调色，统一PC管理端的视觉样式。

- 重写登录页，使用生产流程示意图；保留工号校验、真实登录、密码显示和错误提示。
- 统一导航、顶部路径提示、个人入口和演示环境提示；菜单收起后内容区同步扩展。
- 重排生产全景看板，移除粒子背景和固定一屏高度，采用指标、趋势、生产流程、工单及预警分区；保留真实数据、筛选、刷新和全屏功能。
- 统一表格、输入框、按钮、弹窗、卡片、状态色和MES运营中心页签。
- 适配390px窄屏，宽表保留内部横向滚动，整页不产生横向溢出。

验证：前端类型检查与正式构建通过。使用独立浏览器完成真实登录、首页、MES、日志、基础资料、仓储页面预览；验证菜单折叠、业务弹窗、日志详情和查询。桌面1440px与窄屏390px均未发现整页水平溢出；浏览器无未捕获脚本错误。详细结果见checks.json，预览见login-desktop.png与dashboard.png。

本轮为界面调整，未修改后端业务规则和数据库结构。现有Vite服务会加载新页面，刷新http://127.0.0.1:5174/login即可查看；正式数据入口为5173。
