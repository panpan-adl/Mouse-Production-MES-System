## 四个入口与运行逻辑

1. **仓储基础**：维护物料档案、仓库、库区、库位。页面用深棕标题和浅色结构卡突出“仓库 → 库区 → 库位”；点击仓库可筛选其库区，点击库区可筛选其库位。现有 4 个仓库、7 个库区、7 个库位，保留原记录引用。
2. **入库管理**：全部入库汇总生产退料和产成品入库。生产退料把工单未使用物料退回实体仓库；产成品入库把已完成工序检验的产出分批转入成品仓。采购收货仍在采购管理办理，避免重复入口。
3. **出库管理**：生产领料按工单 BOM 需求选择物料批次，转入工单线边库存；销售发货按销售订单关联成品批次，检验后过账。装箱是包装批次关联，不代替发货。各标签现在使用独立路由，标题、激活状态、列表和新建单据类型一致。
4. **库存管理**：默认显示有余额的库存，可取消勾选查看已用完批次。支持物料、仓库、库位筛选；表格显示库区、库位、批次名称和单位。低库存按物料汇总实体仓余额，不将单个批次余额误当成物料总库存；不计工单线边库。小于安全库存阈值时显示预警及缺口，阈值 0 表示关闭预警，可展开“配置物料安全库存阈值”修改并保存。批次追溯可按工单查看真实关联流水。

## 推荐答辩顺序

1. 打开仓储基础，说明仓库、库区、库位的逐级关系；展示原料收货一区/二区、成品合格区/待发货区。
2. 在生产工单中定位 **MO-000005**，说明 100 只鼠标的计划、12 种叶子物料及四道工序。
3. 打开出库管理的生产领料，展示该工单“BOM成套领料”和“退料复核后补领”单据。
4. 打开入库管理，分别展示“未用物料退库复核”及两张 50 只的成品入库单。
5. 打开销售发货，展示首批 50 只的交付记录；说明生产完成、入库与销售交付是不同状态。
6. 在库存明细筛选成品，核对该工单批次余量 50 只。切到批次追溯，选择 MO-000005 展示采购批次、领料、生产产出及交付的关联流水。
7. 打开低库存预警，说明“当前数量 < 安全库存”的规则；两种演示原料设置为比当前余量高 50，便于展示预警，其他演示原料阈值按余量约 25% 配置。原有其他物料阈值保留，预警数量可能多于两条。
