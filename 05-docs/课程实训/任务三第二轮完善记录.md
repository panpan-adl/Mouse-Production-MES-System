# MouseMES 任务三第二轮完善记录

2026年11月7日，本轮将任务三的数据库验证从HTTP替身推进到独立真实Neo4j与MySQL，同时完善资料范围、实体关联查询、图谱导出和可恢复的删除重试。代码位于feature/task3-graphrag分支，原有登录及订单页面的未提交改动保留。

## 新增行为

| 场景 | 现在的行为 |
| --- | --- |
| 仅询问某份资料 | 页面选择资料范围后，三种问答模式都只检索所选有效版本；无权资料整体拒绝 |
| 首屏关系超过150条 | 可从整个授权图数据库查询实体附近的两跳关系，而非只在已加载首屏中查找 |
| 保存展示依据 | 导出当前图谱JSON，包含范围、截断标识、实体关系和原文引用 |
| 模型配置是否真的可用 | 单独的模型测试请求与“已填写配置”分开显示；测试成功仍需核对实际抽取质量 |
| 文件重叠分块 | 相同实体、关系和原文的重复抽取在发布前去重 |
| 删除时Neo4j离线 | MySQL记录DELETED_PENDING，资料立即退出检索，刷新页面后继续显示待清理项 |
| 删除后又更新同一文件 | 清理按版本上界执行，不会删除更高版本关系；完成确认只修改对应删除版本 |
| 任务二检索返回异常 | 服务端拒绝无权片段、过期内容、空片段和超过约定数量的召回结果 |
