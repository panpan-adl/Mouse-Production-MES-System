# MouseMES 任务三第三轮完善与验收记录

本轮按2026年11月14日提交准备，继续完成不依赖任务二的GraphRAG质量改进、真实生命周期验收和演示材料。新增后端状态版本为task3-r3，可通过 `/api/knowledge/status` 的revision字段确认当前加载版本。

## 一 已完成的改进

- 实体简称定位：直接匹配失败时，将当前用户当前版本的候选名称交给模型选择，校验候选白名单后再检索两跳关系。
- 回答版本复核：模型返回后复核来源仍是有效构建，避免生成期间被更新或删除的资料形成过时答案。
- 资料不足处理：允许明确的固定拒答句，不为不存在的事实伪造引用；其他答案仍须真实来源编号，校验失败最多修正一次。
- 图谱节点聚焦：可只看当前选中节点的直接关系，并恢复全图。
- 问答导出：保存实际问题、答案、检索方式、资料版本和原文；支持清空本页对话及Ctrl加Enter发送。
- 保留密钥环境的重启脚本：先校验原后端进程身份和配置，备份旧包，再构建重启；失败时尝试回滚，不停止前端或数据库。

## 四 部署与最终复验

在原来配置API密钥的PowerShell窗口运行：

```powershell
.\08-environment\Restart-Knowledge-Backend.ps1
```

脚本不会重新索要密钥，也不把密钥保存到文件；需要继承该窗口原有的环境变量。若窗口已关闭，先重新运行Use-Knowledge-Ark.ps1配置，再设置Neo4j地址和密码。版本更新后，重新执行：

```powershell
python 07-tools-barcodes/verify_knowledge_live.py --run-live
```

该命令会调用真实模型并写入临时验收资料，需保持服务正常运行。普通单元测试与界面替身测试不会调用外部模型。
