# 表单与设备入口优化说明

本次落实五项使用反馈：

1. 申请、生产、仓储、质检、设备及配置等30个页面接入统一草稿保存。关闭填写界面、切换页面或刷新后，再次打开相同表单自动恢复。草稿按账号、页面、弹窗类型及编辑记录分别存储在当前浏览器；密码、令牌等字段不进入草稿。
2. 周期保养的“每隔”和“提前提醒天数”默认值、最小值均为1，步长为1；后端对提前提醒同步执行1至365天整数校验。旧计划编辑时自动将低于1的值修正为1。
3. 维修申请与派工、维修执行与记录、维护账单统一进入“设备维修管理”。同一组维修记录分别用于申请派工、执行和已完成账单展示；费用来自完成填报，避免重复录单。旧维修任务及账单链接跳转至合并模块对应页签。
4. 删除智能业务查询的独立菜单及页面入口，旧地址转到Skill业务智能体；库存图表明细入口转到库存与批次追溯。
5. 保存成功后统一关闭填写弹窗并清除对应草稿；验证失败或接口报错保留内容。创建工单后不再自动打开下一张领料表单。
