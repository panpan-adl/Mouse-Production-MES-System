# MouseMES Dify OP30 质检演示

1. 在 https://cloud.dify.ai/ 登录，进入工作室，导入同目录 MouseMES-OP30.yml。
2. 在画布点测试运行：DEMO-M72-041 与 0.26 应得到扭矩偏低；0.30 应得到合格。测试后发布工作流。
3. 在该工作流的 API 访问 / API 密钥中创建应用密钥。它不是方舟 Key。
4. 打开 PowerShell，执行以下命令。提示时粘贴 Dify 应用密钥。随后按项目启动器提示输入方舟 Key（供原知识库使用）。

```powershell
Set-Location -LiteralPath 'D:\专业实训 4-3\Mouse-Production-MES-System'
$secret = Read-Host '粘贴 Dify 应用密钥' -AsSecureString
$env:MES_DIFY_API_KEY = [System.Net.NetworkCredential]::new('', $secret).Password
try { & '.\启动任务二.cmd' } finally { Remove-Item Env:MES_DIFY_API_KEY -ErrorAction SilentlyContinue; $secret.Dispose() }
```

5. 登录 MouseMES，在「智能与提醒 → OP30 扭矩质检（Dify）」运行同样两组输入。结果下面的 Dify 运行编号可用于对照工作室日志。

表单只发送演示工单号、扭矩和随机运行标识，不发送私有文档或 MES 用户信息。工作流不查询实时数据、不写回 MES，也不调用模型。后端仅使用 Dify Cloud 官方固定接口，应用密钥不进入页面、Git 或命令历史。密钥仅在本次启动进程中生效，下次重新启动需要重新输入。

## 真实工单复核

导入并发布同目录的 MouseMES-真实工单扭矩复核.yml，将该应用密钥配置为后端环境变量 MES_DIFY_PRODUCTION_API_KEY。
在 OP30 页面选择真实工单，按工艺文件录入上下限和实测扭矩。Dify 接收三个扭矩数值，工单详情由 MouseMES 查询。
