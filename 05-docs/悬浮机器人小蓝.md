# 悬浮机器人「小蓝」

小蓝出现在登录后的业务页面右下角，包括 Skill 智能体工作台。形象采用浅蓝渐变机身、鼠耳轮廓、深色屏幕脸和青色表情，使用项目内 SVG 绘制，无外部图片依赖。

- 点击机器人展开业务对话小窗；可通过快捷技能或输入任务查询真实业务数据。
- 机器人有轻微悬浮、眨眼、招手动画，处理任务时切换表情。尊重系统“减少动态效果”设置。
- 拖动机器人可调整位置，刷新后记住位置；窗口缩小时自动限制在屏幕内。
- 小窗显示前5条结果、来源与时间，完整结果跳转到同一个任务记录。补货确认等操作继续在完整工作台核对执行。
- 当前浏览器中的页面导航保留小窗会话；刷新后可从工作台任务历史恢复记录。退出或切换账号清除内存中的小窗会话，不将业务结果持久化到本地存储。
- 面板右上角横线可收起；Esc 收起后恢复机器人按钮的键盘焦点。Ctrl+Enter 可发送任务。

页面地址：http://127.0.0.1:5174/assistant 。当前模型模式仍以服务端配置为准；形象升级不会自动启用远程大模型。

验证：前端类型检查和构建通过；浏览器实测拖动不误触、真实库存查询、完整任务定位、跨页保留会话、Esc与焦点恢复、位置记忆、手机面板边界、减少动态效果，共7项检查通过，未发现页面脚本错误。
