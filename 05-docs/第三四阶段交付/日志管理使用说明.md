# 日志管理使用说明

入口：登录后展开左侧“系统管理”，点击“日志管理”。
演示地址：http://127.0.0.1:5174/system/logs
正式地址：http://127.0.0.1:5173/system/logs
访问岗位：CEO（角色9）与系统管理员（角色11）。全功能演示账号109001，密码123456。

页面提供三个页签：

- 业务审计：读取mm_audit，显示操作人、业务、动作、关联编号及记录时间。
- 操作日志：读取t_operation_log，显示操作人、模块、动作、成功/失败及请求地址等详情。
- 登录日志：读取t_login_log，显示成功/失败、账号、时间、IP及现有浏览器信息。

支持关键词、起止日期、成功/失败（登录与操作日志）、分页、刷新与详情。业务审计标注“已记录”，不会把审计凭据误标为业务结果成功。

接口：GET /api/mes/system-logs。管理员权限由服务端检查；匿名请求返回401，普通员工返回403。每页最多100条；查询参数通过预编译SQL传入。页面不展示原始请求正文、响应正文、登录令牌和密码字段，不提供修改/删除记录。

历史审计中未记录关联编号的条目显示“未提供”，不会自动补造编号。页面只展示已经留下的日志；本次增加的是统一查看入口，不能据此声称旧系统的所有业务操作和失败请求均已具备完整日志。

验证：前端类型检查与正式构建通过，现有后端单元测试通过；专项接口检查20项，覆盖三类真实数据、分页、日期、状态、空结果、非法条件及访问权限。部署后复验同一专项脚本。

注意：配置过角色菜单白名单的系统管理员，需要同时获得/system/logs页面授权；CEO不受菜单白名单限制。
