## 生产工单、领料与退料

1. 进入生产工单，点击新建生产工单。选择已配置BOM与工艺路线的产品、生产数量及默认负责人。备货可不关联销售订单；订单生产须选择匹配订单。
2. 无BOM或无工艺的产品会明确标记并禁止选择，防止选中后出现空的配置列表。BOM和路线会依据产品带出。
3. 在生产领料页可点击“先创建生产工单”；保存成功后，系统直接打开领料草稿并关联刚创建的工单。
4. 新建领料单，选择工单与出库仓库。可点击“按工单BOM带出待领物料与批次”，也可逐行选择物料和实际库存批次。单一库位时自动带出，多库位时需核对实际库位。
5. 保存草稿后确认并执行过账，原仓减少、工单线边库增加。BOM带出遇到库存不足会提示，不会伪造库存。
6. 退料页仅列出线边有余料的工单。选择物料、原批次及目的仓库库位，填写退料原因后保存、确认并执行过账。

生产工单、生产领料单和生产退料单是三种不同业务凭据。新工单尚未领料时不能直接退料；已经消耗的物料也不能凭空退回。

## 供应商退货

进入采购管理→供应商退货，点击新建供应商退货单。选择原采购单、退货仓库和原收货物料批次，填写数量与退货原因。批次选项按原采购收货数量、累计已退数量及所选仓库存量限制。保存后确认并执行过账，系统扣减实际库存。此页面只显示供应商退货记录，不再混在所有仓储单据中。

## 装箱管理

1. 新建包装箱，填写客户/关联订单（均可选）、尺寸与重量。订单改为选择真实销售单，不必手填数据库编号。
2. 点击装入物料，从已入库的半成品或成品库存选择。线边在制品不会作为可装箱库存显示；无可用库存时可直接前往产成品入库。
3. 填写数量并保存，确认装箱后查看箱内物料、批次及二维码。
4. 外箱可装入已确认、未归属其他父箱且客户与订单匹配的内箱，再确认外箱。追溯会展开子箱内容。防循环、数量校验等原服务端规则保留。
