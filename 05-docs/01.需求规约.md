# 鼠标制造执行系统 - 需求规约

## 1. 引言

### 1.1 编写目的
本需求规约文档旨在详细描述鼠标制造执行系统（Mouse MES）的功能需求、非功能需求、数据需求和业务流程，为项目开发、测试和验收提供明确的依据。本文档将作为项目开发的指导性文件，确保系统开发符合用户需求和业务流程。

### 1.2 项目背景
传统鼠标制造企业面临生产流程不透明、信息孤岛、效率低下等问题。随着市场竞争的加剧，企业需要提升生产管理水平，实现精细化管理。本系统旨在通过数字化手段，实现生产全流程的可视化管理，提升企业运营效率和管理水平，增强企业竞争力。

### 1.3 项目目标
- 实现生产全流程数字化管理，消除信息孤岛
- 提升订单处理效率，缩短订单周期
- 优化生产计划与调度，提高设备利用率
- 加强质量管理，提升产品合格率
- 实现库存精细化管理，降低库存成本
- 提供数据决策支持，辅助管理层决策

### 1.4 术语定义

| 术语 | 定义 |
|------|------|
| MES | 制造执行系统（Manufacturing Execution System），用于管理和监控车间生产活动的信息系统 |
| ERP | 企业资源计划（Enterprise Resource Planning），整合企业资源的管理系统 |
| WMS | 仓库管理系统（Warehouse Management System），用于仓库库存管理的系统 |
| 工单 | 生产任务的基本单元，包含生产数量、产品信息、工艺路线等 |
| BOM | 物料清单（Bill of Materials），描述产品组成结构的清单 |
| 条码 | 用于标识产品、订单、物料的编码，便于快速识别和追溯 |
| 报工 | 生产人员上报实际生产数量和工时的过程 |
| 质检 | 对产品进行质量检验的过程 |
| 采购订单 | 向供应商采购物料的订单 |
| 销售订单 | 客户下达的产品销售订单 |

## 2. 功能需求

### 2.1 用户认证与权限管理

#### 2.1.1 用户登录
- 用户通过工号和密码登录系统
- 工号为6位数字，密码至少6位字符
- 登录失败次数超过5次，账号锁定1小时
- 登录成功后记录登录时间和IP地址

#### 2.1.2 用户退出
- 用户点击退出按钮安全退出系统
- 清除当前登录状态和缓存数据

#### 2.1.3 权限管理
- 基于角色的访问控制（RBAC）
- 不同角色拥有不同的菜单访问权限
- 管理员可自定义角色权限
- 权限变更实时生效

### 2.2 销售订单管理

#### 2.2.1 订单创建
- 用户可创建新的销售订单
- 填写客户名称、联系人、联系电话等客户信息
- 选择产品，输入数量和单价
- 系统自动计算总金额
- 生成唯一订单号（格式：ORD-YYYYMMDDXXX）
- 订单创建时间自动记录

#### 2.2.2 订单列表
- 展示所有订单列表，支持分页
- 支持按订单状态筛选（待确认、已确认、已完成、已取消）
- 支持按订单号、客户名称搜索
- 列表显示订单号、客户名称、产品、数量、金额、状态、创建时间

#### 2.2.3 订单详情
- 查看订单完整信息，包括客户信息、产品明细、订单状态
- 确认订单操作，确认后自动生成生产计划
- 取消订单操作，订单状态变为已取消
- 打印订单功能

#### 2.2.4 扫码录入
- 点击扫码录入按钮弹出弹窗
- 用户输入订单号进行查询
- 订单存在则跳转订单详情页面
- 订单不存在则提示用户，可选择创建新订单
- 支持条形码扫描枪直接输入

### 2.3 采购管理

#### 2.3.1 采购需求
- 创建采购需求单，关联物料信息
- 填写需求数量、需求日期
- 需求单状态管理（待审核、已审核、已完成）
- 需求单列表展示和搜索

#### 2.3.2 采购订单
- 根据采购需求创建采购订单
- 选择供应商，填写采购数量、单价
- 系统自动计算总金额
- 生成唯一采购订单号
- 采购订单状态管理（待确认、已确认、已到货、已完成）

#### 2.3.3 供应商管理
- 供应商信息维护（新增、编辑、删除）
- 供应商列表展示，支持搜索和筛选
- 供应商信息包括：名称、联系人、联系电话、地址、合作状态
- 供应商评级管理

### 2.4 生产管理

#### 2.4.1 生产计划
- 订单确认后自动生成生产计划
- 计划包含产品信息、计划数量、计划开始时间、计划结束时间
- 计划进度可视化展示（进度条、甘特图）
- 计划状态管理（计划中、进行中、已完成、已取消）
- 计划调整和变更功能

#### 2.4.2 生产任务
- 生产计划分解为生产任务
- 任务分配给车间和操作工
- 任务状态更新（待分配、已分配、进行中、已完成）
- 任务进度跟踪

#### 2.4.3 生产报工
- 操作工通过扫码或手动输入进行报工
- 输入实际生产数量、工时
- 报工记录自动保存
- 报工数据实时更新到工单进度
- 报工统计和查询

#### 2.4.4 工单管理
- 工单列表展示，支持分页和筛选
- 工单详情查看，包含产品信息、数量、状态、进度
- 工单关联生产订单和生产计划
- 工单状态管理（待开始、进行中、已完成、已关闭）

### 2.5 质量管理

#### 2.5.1 质检任务
- 创建质检任务，关联订单或工单
- 选择质检类型（来料检验、过程检验、成品检验）
- 分配质检员
- 质检任务状态管理（待质检、质检中、已完成）

#### 2.5.2 质检记录
- 质检结果录入，包括合格数量、不合格数量、不合格原因
- 质检记录查询，支持按订单号、产品名称、质检结果筛选
- 质检统计分析，生成质检报告
- 不合格品处理流程

#### 2.5.3 质检标准
- 质检标准维护，新增、编辑、删除
- 标准包含检验项目、检验方法、合格标准
- 质检标准关联产品

### 2.6 仓库管理

#### 2.6.1 库存管理
- 实时库存查询，支持按产品名称、仓库筛选
- 库存预警，低于安全库存自动提示
- 库存盘点功能
- 库存统计报表

#### 2.6.2 物料管理
- 物料信息维护，新增、编辑、删除
- 物料分类管理
- 物料规格型号管理

#### 2.6.3 入库管理
- 成品入库，关联订单信息
- 采购入库，关联采购订单
- 入库记录查询
- 入库单打印

#### 2.6.4 出库管理
- 生产领料，关联工单
- 销售出库，关联销售订单
- 出库记录查询
- 出库单打印

### 2.7 设备管理

#### 2.7.1 设备台账
- 设备信息维护，新增、编辑、删除
- 设备信息包括：名称、编号、规格型号、购买日期、状态
- 设备列表展示，支持搜索和筛选

#### 2.7.2 设备维修
- 创建维修任务，关联设备
- 填写维修类型、维修内容、维修人员
- 维修记录查询
- 维修统计分析

#### 2.7.3 设备维护
- 设备定期维护计划制定
- 维护任务分配
- 维护记录查询

### 2.8 考勤管理

#### 2.8.1 考勤打卡
- 上班打卡和下班打卡
- 打卡时间自动记录
- 打卡记录查询
- 迟到、早退、旷工自动判断

#### 2.8.2 请假管理
- 请假申请，填写请假类型、时间、原因
- 请假审批流程
- 请假记录查询

### 2.9 财务看板

#### 2.9.1 财务统计
- 销售额统计（日报、周报、月报）
- 采购成本统计
- 利润分析

#### 2.9.2 报表展示
- 财务报表生成
- 图表可视化展示

### 2.10 系统管理

#### 2.10.1 用户管理
- 用户信息维护，新增、编辑、删除
- 用户列表展示，支持搜索和筛选
- 用户状态管理（在职、离职）
- 密码重置功能

#### 2.10.2 角色管理
- 角色信息维护，新增、编辑、删除
- 角色权限配置
- 角色列表展示

#### 2.10.3 部门管理
- 部门信息维护，新增、编辑、删除
- 部门层级管理
- 部门列表展示

## 3. 非功能需求

### 3.1 性能需求
- 系统响应时间不超过2秒
- 支持至少50个并发用户同时在线
- 数据查询响应时间不超过1秒
- 报表生成时间不超过10秒

### 3.2 兼容性需求
- 支持Chrome、Firefox、Edge浏览器
- 支持微信小程序运行
- 支持Windows 10及以上操作系统

### 3.3 安全性需求
- 用户密码加密存储（MD5）
- 使用HTTPS加密传输
- 接口访问权限控制
- 操作日志记录
- SQL注入防护

### 3.4 可用性需求
- 系统可用性达到99.9%
- 数据定期备份
- 故障恢复时间不超过1小时

### 3.5 易用性需求
- 界面简洁美观，操作直观
- 提供操作指引和帮助文档
- 支持快捷键操作

#### 4.1.3 产品实体

#### 4.1.4 生产计划实体
- 计划ID、订单ID、产品ID、计划数量、计划时间、状态、创建时间

#### 4.1.5 工单实体
- 工单ID、生产订单ID、产品ID、产品名称、数量、状态、创建时间

#### 4.1.6 库存实体
- 库存ID、产品ID、仓库ID、数量、创建时间

#### 4.1.7 角色实体
- 角色ID、角色名称、角色描述

#### 4.1.8 部门实体
- 部门ID、部门名称、父部门ID、创建时间

### 4.2 数据关系
- 用户与角色：多对一关系
- 用户与部门：多对一关系
- 订单与产品：多对一关系
- 生产计划与订单：多对一关系
- 工单与生产订单：多对一关系
- 库存与产品：多对一关系

### 4.3 数据存储
- 数据库：MySQL 8.0+
- 缓存：Redis 7.0+
- 字符集：UTF-8

## 5. 业务流程

### 5.1 订单处理流程
```
客户下单 → 创建销售订单 → 订单确认 → 生成生产计划 → 生产任务分配 → 工单执行 → 生产报工 → 成品入库 → 销售出库 → 订单完成
```

### 5.2 生产流程
```
生产计划制定 → 生产任务分配 → 操作工报工 → 质检 → 成品入库
```

### 5.3 采购流程
```
采购需求提报 → 采购需求审核 → 创建采购订单 → 供应商确认 → 到货入库 → 采购完成
```

### 5.4 库存流程
```
入库：采购入库/成品入库 → 库存增加
出库：生产领料/销售出库 → 库存减少
```

### 6.1 认证接口
- POST /api/auth/login：用户登录
- POST /api/auth/logout：用户退出

### 6.2 订单管理接口
- GET /api/order/list：订单列表
- POST /api/order/create：创建订单
- GET /api/order/{id}：订单详情
- PUT /api/order/confirm/{id}：确认订单

### 6.3 生产管理接口
- GET /api/plan/list：生产计划列表
- GET /api/workorder/list：工单列表
- POST /api/workorder/report：报工提交

### 6.4 库存管理接口
- GET /api/inventory/list：库存列表
- POST /api/inventory/in：入库操作
- POST /api/inventory/out：出库操作

### 6.5 用户管理接口
- GET /api/user/list：用户列表
- POST /api/user/create：创建用户
- PUT /api/user/{id}：更新用户
- DELETE /api/user/{id}：删除用户
