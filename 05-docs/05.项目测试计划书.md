# 鼠标制造执行系统 - 项目测试计划书

## 1. 引言

### 1.1 编写目的
本测试计划书旨在详细描述鼠标制造执行系统（Mouse MES）的测试策略、测试范围、测试方法和测试流程，确保系统功能的正确性和稳定性。

### 1.2 测试目标
- 验证系统功能符合需求规约
- 发现潜在的功能缺陷和性能问题
- 确保系统在不同环境下稳定运行
- 提供完整的测试报告和缺陷清单

## 2. 测试范围

### 2.1 功能测试范围

| 模块 | 测试内容 |
|------|----------|
| 用户认证 | 登录、退出、权限控制 |
| 订单管理 | 订单创建、查询、确认、取消 |
| 生产管理 | 生产计划、任务、工单、报工 |
| 采购管理 | 采购需求、订单、供应商管理 |
| 质量管理 | 质检任务、记录、标准管理 |
| 仓库管理 | 库存查询、出入库操作 |
| 设备管理 | 设备台账、维修、维护 |
| 考勤管理 | 考勤记录、请假管理 |
| 财务看板 | 财务统计、报表展示 |
| 系统管理 | 用户、角色、部门管理 |

### 2.2 非功能测试范围
- 性能测试：响应时间、并发用户数
- 兼容性测试：不同浏览器、不同设备
- 安全测试：权限控制、数据加密
- 易用性测试：操作流程、界面友好性

## 4. 测试方法

### 4.1 黑盒测试
- 不考虑内部实现，只验证输入输出
- 覆盖所有功能点和业务流程

### 4.2 白盒测试
- 检查代码逻辑和路径覆盖
- 重点关注关键业务逻辑

### 4.3 自动化测试
- 接口自动化测试
- 前端UI自动化测试

### 4.4 手动测试
- 用户界面测试
- 交互流程测试
- 易用性测试

## 5. 测试流程

### 5.1 测试阶段

| 阶段 | 时间 | 内容 |
|------|------|------|
| 单元测试 | 7.10-7.12 | 后端接口测试、前端组件测试 |
| 集成测试 | 7.13-7.14 | 前后端联调测试 |
| 系统测试 | 7.15-7.16 | 完整系统功能测试 |
| 回归测试 | 7.17 | Bug修复后验证 |

### 5.2 测试流程

```
编写测试用例 → 执行测试 → 记录缺陷 → 提交缺陷报告 → 开发修复 → 回归测试 → 测试通过
```

## 7. 缺陷管理

### 7.1 缺陷分类

| 级别 | 定义 | 示例 |
|------|------|------|
| 致命 | 系统无法启动或核心功能无法使用 | 登录失败、订单创建失败 |
| 严重 | 重要功能缺陷，影响业务流程 | 报工数据丢失、库存计算错误 |
| 一般 | 次要功能缺陷，不影响主要流程 | 界面显示异常、按钮样式错误 |
| 轻微 | 不影响功能的小问题 | 拼写错误、格式问题 |

### 7.2 缺陷报告格式

| 字段 | 说明 |
|------|------|
| 缺陷编号 | 唯一标识 |
| 缺陷标题 | 简洁描述 |
| 缺陷级别 | 致命/严重/一般/轻微 |
| 所属模块 | 相关模块 |
| 复现步骤 | 详细操作步骤 |
| 预期结果 | 期望行为 |
| 实际结果 | 实际行为 |
| 截图 | 问题截图 |
| 优先级 | 修复优先级 |
