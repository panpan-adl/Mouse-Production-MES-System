# 鼠标制造执行系统 - 项目概要设计书

## 1. 引言

### 1.1 编写目的
本概要设计书旨在详细描述鼠标制造执行系统（Mouse MES）的技术架构、模块设计、数据库设计和接口设计，为开发人员提供明确的开发指南。

### 1.2 项目背景
基于需求规约文档，本系统采用前后端分离架构，后端使用Spring Boot，前端使用Vue 3，移动端使用微信小程序，实现生产全流程数字化管理。

## 2. 系统架构设计

### 2.1 架构风格
采用微服务架构风格，前后端分离，通过RESTful API进行通信。

| API路径 | 方法 | 功能 |
|---------|------|------|
| /api/auth/login | POST | 用户登录 |

**请求参数**：
```json
{
  "userCode": "string (工号)",
  "password": "string (密码)"
}
```

**响应参数**：
```json
{
  "code": "int (状态码)",
  "message": "string (消息)",
  "data": {
    "id": "int (用户ID)",
    "userCode": "string (工号)",
    "realName": "string (真实姓名)",
    "roleName": "string (角色名称)",
    "deptName": "string (部门名称)"
  }
}
```

## 6. 安全设计

### 6.1 用户认证
- 使用token进行身份验证
- 登录成功后返回token，存储在localStorage
- 每次请求携带token

### 6.2 权限控制
- 基于角色的访问控制（RBAC）
- 不同角色访问不同页面和接口
- 路由守卫验证权限

### 6.3 数据安全
- 使用HTTPS加密传输
- 密码加密存储（MD5）
- SQL注入防护
