## 设备管理

菜单顺序为“设备台账 → 设备维修 → 点检与保养”。

- **设备台账**：登记设备档案、位置与负责人，展示正常、待维修、维修中、报废状态；每台设备可点“维修记录”，下方显示其原始维修单、问题描述、处理内容、维修人、费用与完成时间。不再把报修放在台账下。
- **设备维修**：上层标签先显示“设备报修”，再显示“维修管理”。报修选择设备、填写问题后生成维修单；维修管理原有“申请与派工、维修执行与记录、维护账单”保留。
- **点检与保养**：上层标签调整为“点检配置与记录 → 保养计划与执行”。点检项目定义标准，检查计划关联设备和项目，执行结果保留记录；异常点检可自动关联维修单。周期保养按实际计划生成待办，开始、完成后回写执行时间、结果和费用。

设备状态原先只识别 FAULT/MAINTAINING，实际维修流程返回 REPAIR_REQUESTED/REPAIRING，已修正台账及报修页的显示与计数。管理账号现在也能查看维护员名下的周期保养执行记录。
