# 申请校验与人员指派修复

- 保存按钮和表单提交统一检查必填、空白文本、有效选项、数值范围／步长和起止时间。校验失败在弹窗内部列出具体问题、标出错误字段并定位首个错误，不触发保存处理。
- 本地业务检查和后端返回的业务失败原因也在当前填写窗口显示；失败保留界面和草稿。成功仍由原保存成功分支关闭窗口并清除对应草稿。
- 维修／周期保养／点检只选择在职且岗位启用的设备维护员；生产工单及任务只选择操作工。自定义岗位按实际业务权限参与筛选。前端不再回退到全部员工或演示管理员。
- 后端在创建、指派和周期任务生成时再次校验人员资格，防止失效的历史选择或伪造请求写入。
- 新增验证：6项表单校验回归、3项人员资格单元测试、4项维修拒绝写入单元测试，以及实际MySQL人员筛选检查；保留7项草稿回归。

前端测试：`npm run test:validation`、`npm run test:drafts`、`npm run build`。
数据库筛选验证：`python 07-tools-barcodes/verify_assignment_eligibility.py`，只使用隔离数据库中的连接级临时表。
