# 科技视觉改版

当前版本按用户要求采用浅蓝色科技视觉：天空蓝渐变背景、冰蓝玻璃卡片、蓝色文字与少量淡紫装饰，保留原有业务流程和数据来源。配色在 sky-theme.css 中统一维护。

- 登录页：参考用户提供的“新质生产力”页面，将稀疏连线改为立体点云球。桌面约 6200 颗粒子，手机约 2100 颗，具有进入聚拢、缓慢自转、前后景透明度与大小差异、轻微波动、鼠标避让与视差。保留环绕业务节点、透视网格、玻璃质感登录卡片。
- 工作区：动态背景、光轨、发光导航与卡片、仪表盘装饰环、浅蓝表格和表单。
- 动效控制：登录页右下角与工作区顶部均提供开关，选择保存在当前浏览器；隐藏页面会停止粒子绘制，尊重系统减少动态效果设置，手机端自动降低粒子数量。
- 所有装饰层不接收点击，不影响按钮、表单及业务交互。

## 验证

前端类型检查及生产构建通过。浏览器实测登录、生产看板、MES 运营中心、系统日志、物料、履约页面，检查菜单折叠、日志查询与详情、仓储弹窗取消，以及手机端布局；未发现页面脚本错误或横向溢出。

另外实测粒子变化、暂停静止、恢复、刷新后记忆、工作区开关及减少动态效果模式，均通过。新版点云也复核桌面与手机端的真实登录、手机无横向溢出。测试只查看业务数据和取消弹窗，没有新建业务单据。
