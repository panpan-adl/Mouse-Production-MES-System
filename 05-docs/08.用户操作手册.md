# 鼠标制造执行系统 - 用户操作手册

## 1. 系统概述

### 1.1 系统简介
鼠标制造执行系统（Mouse MES）是一套专为鼠标制造企业设计的生产管理系统，涵盖订单管理、生产管理、质量管理、仓库管理等核心业务模块，实现生产全流程数字化管理。

### 1.2 系统特点
- 功能全面：覆盖生产全流程管理
- 操作简便：直观的界面设计，易于上手
- 实时数据：生产进度、库存变化实时更新
- 移动端支持：微信小程序随时随地办公

### 1.3 适用角色
- 生产经理：负责生产计划和资源调配
- 车间主任：负责车间生产管理
- 操作工：执行生产任务和报工
- 质检员：执行质检任务
- 仓管员：管理仓库库存
- 采购专员：负责采购业务
- 销售专员：负责销售订单
- 设备维护员：负责设备维护

## 2. 系统登录

### 2.1 管理后台登录

**操作步骤：**
1. 打开浏览器，输入地址：`http://localhost:5173`

## 4. 订单管理

### 4.1 订单列表

**操作步骤：**
1. 点击左侧菜单"订单管理" -> "订单列表"
2. 查看订单列表，支持按状态筛选和搜索

**筛选条件：**
- 订单状态：全部、待确认、已确认、已完成、已取消
- 搜索：订单号、客户名称

### 4.2 创建订单

**操作步骤：**
1. 点击"新建订单"按钮
2. 填写订单信息：
   - 客户名称
   - 产品选择
   - 数量
   - 单价
3. 点击"保存"按钮

**注意事项：**
- 订单号自动生成，格式为：ORD-YYYYMMDDXXX
- 总金额自动计算

### 4.3 订单详情

**操作步骤：**
1. 在订单列表中点击某订单
2. 查看订单详情信息
3. 可执行确认订单、取消订单等操作

### 4.4 扫码录入

**操作步骤：**
1. 点击"扫码录入"按钮
2. 在弹出的弹窗中输入订单号
3. 点击"查询"按钮
4. 如果订单存在，跳转到订单详情页面
5. 如果订单不存在，可选择创建新订单

## 5. 生产管理

### 5.1 生产计划

**操作步骤：**
1. 点击左侧菜单"生产管理" -> "生产计划"
2. 查看生产计划列表
3. 点击计划查看详情或更新状态

**计划状态：**
- 计划中：正在制定生产计划
- 进行中：生产计划执行中
- 已完成：生产计划已完成

### 5.2 生产任务

**操作步骤：**
1. 点击左侧菜单"生产管理" -> "生产任务"
2. 查看生产任务列表
3. 选择任务进行分配或查看详情

### 5.3 工单管理

**操作步骤：**
1. 点击左侧菜单"生产管理" -> "工单管理"
2. 查看工单列表
3. 点击工单查看详情

**工单信息：**
- 生产订单号
- 产品名称
- 数量
- 状态

### 5.4 生产报工

**操作步骤：**
1. 点击左侧菜单"生产管理" -> "生产报工"
2. 选择要报工的工单
3. 输入生产数量
4. 点击"提交报工"按钮

**注意事项：**
- 报工数量不能超过工单剩余数量
- 报工后工单进度自动更新

## 13. 常见问题

### 13.1 登录问题

**问题：登录失败，提示"工号或密码错误"**
**解决方案：**
- 检查工号是否正确（6位数字）
- 检查密码是否正确（初始密码123456）
- 联系系统管理员重置密码

**问题：登录失败，提示"网络连接失败"**
**解决方案：**
- 检查网络连接
- 检查后端服务是否启动
- 检查端口是否正确（8080）

### 13.2 操作问题

**问题：订单创建失败**
**解决方案：**
- 检查必填项是否填写完整
- 检查产品是否选择
- 检查数量是否大于0

**问题：报工失败**
**解决方案：**
- 检查工单是否存在
- 检查报工数量是否超过剩余数量

**问题：出库失败**
**解决方案：**
- 检查库存数量是否充足
- 检查产品是否选择

### 13.3 数据问题

**问题：数据显示不完整**
**解决方案：**
- 刷新页面
- 检查网络连接
- 联系技术支持

**问题：数据错误**
**解决方案：**
- 联系系统管理员进行数据修正
