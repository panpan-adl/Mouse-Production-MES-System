# MouseMES 鼠标生产执行管理系统功能清单

系统围绕鼠标制造，覆盖“销售订单—生产计划—采购备料—生产执行—质量检验—仓储交付”的业务流程，并提供设备、人员、监控和智能辅助功能。

| 模块 | 包含功能 |
| --- | --- |
| 1. 首页与生产看板 | 生产指标统计、小时产量、计划达成率、合格率、工单状态与进度、物料齐套与缺料、库存与安全线、异常提醒；按日期、班次、车间查看。 |
| 2. 销售订单 | 客户资料维护、销售订单登记与查询、订单状态与交付进度跟踪、关联生产计划与工单。 |
| 3. 采购管理 | 采购需求处理、供应商资料维护、采购订单及明细、提交审批、采购收货、来料检验、分批入库、按原采购批次向供应商退货。 |
| 4. 生产管理 | 生产计划、订单工单与备货工单、多级BOM展开及需求计算、工序任务生成、班组排班、轮班日历、任务排产与甘特图、任务拆分与派工、开工、分次报工、报工单审批、进度更新。 |
| 5. 质量管理 | 检验标准、检测项、产品与工序检验模板；来料、过程、出货检验；实测值与合格数量记录、数值上下限判定、质检待办与放行、不合格登记、返工处置与复检、报废处置、质量记录追溯。 |
| 6. 仓储与物料 | 物料档案、仓库/库区/库位、库存查询、物料请求与缺料判断；采购入库、供应商退货、生产领料、生产退料、成品入库、销售发货、销售退货；单据草稿、编辑、确认、取消及过账；库存上下限预警。 |
| 7. 装箱与批次追溯 | 包装箱资料、成品装箱、子箱与外箱关联、装箱确认、箱内明细；物料/仓库/批次库存查询、工单关联流水、生产要素条码与装箱追溯二维码。 |
| 8. 设备管理 | 设备台账及状态、故障报修、维修任务分配与执行、维修结果及费用；点检项目、点检计划与执行记录、异常关联维修；周期保养计划、提前提醒、定期生成保养单、保养执行与历史记录。 |
| 9. 基础配置中心 | 单位及换算、物料与产品分类、产品物料映射、多级BOM与版本、工艺路线与工序、SOP作业指导书、工序耗料配置、车间与工作站资源、班组/成员/班次、排班与节假日、缺陷分类、编码规则。 |
| 10. 考勤与个人中心 | 员工考勤查询、记录维护与状态管理、上下班时间和工时记录；个人资料、头像、密码修改及账号信息查看。 |
| 11. 财务看板 | 销售收入、采购支出、维修费用、库存价值、毛利统计；按月查看趋势、按供应商及物料分析采购支出、质量损失数量统计。 |
| 12. 系统管理与日志 | 员工、部门、岗位与角色管理、岗位权限及菜单授权、账号状态维护、字典与系统参数；登录日志、操作日志、业务审计的检索与详情查看。 |
| 13. 系统监控 | 在线用户与会话退出、服务运行时间、内存/处理器指标、数据库状态、Redis缓存指标、后台定时任务启停/执行及运行记录。 |
| 14. 通知与自动任务 | 公告发布、岗位定向通知、已读状态；报工后自动生成质检待办、事件执行日志与失败重试、安全库存补货建议、周期点检与保养任务调度。 |
| 15. Skill业务智能体与“小蓝”机器人 | 库存查询、缺料分析、工单追溯、点检保养待办查询、补货建议核对与确认；任务历史、结果来源、岗位权限；悬浮机器人、拖动与位置记忆、对话小窗、完整任务跳转。 |
| 16. 综合工作台 | MES运营中心集中处理排产、报工审批、线边库存、单据、装箱、不合格及监控；制造与质量放行工作台串联工序和检验；生产与仓储流程总览提供阶段待办与模块入口。 |

主业务流程：销售订单 → 生产计划/工单 → BOM需求计算 → 采购与来料检验 → 领料 → 排产与工序报工 → 过程检验及放行 → 成品入库 → 装箱 → 出货检验与发货 → 批次追溯。

说明：不同岗位可见菜单及可执行操作不同。仓储草稿不会改变库存，过账后才产生实际库存变动。智能体当前可使用本地技能；远程大模型已预留接入，真实调用需完成接口配置后验证。补货确认只登记建议，不自动创建采购订单。财务看板提供业务统计，不等同完整财务核算软件。
