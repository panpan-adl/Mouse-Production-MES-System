# 鼠标制造执行系统 - 项目开发计划书

## 1. 引言

### 1.1 编写目的
本项目开发计划书旨在详细描述鼠标制造执行系统（Mouse MES）的开发计划、进度安排、技术方案和团队分工，为项目开发提供明确的指导和依据。

### 1.2 项目概述
鼠标制造执行系统是一套专为鼠标制造企业设计的生产管理系统，涵盖订单管理、生产管理、质量管理、仓库管理等核心业务模块，实现生产全流程数字化管理。

### 1.3 项目目标
- 实现生产全流程数字化管理，消除信息孤岛
- 提升订单处理效率，缩短订单周期
- 优化生产计划与调度，提高设备利用率
- 加强质量管理，提升产品合格率
- 实现库存精细化管理，降低库存成本

## 2. 项目范围

### 2.1 功能范围
- 用户认证与权限管理
- 销售订单管理（创建、查询、确认、扫码录入）
- 采购管理（采购需求、采购订单、供应商管理）
- 生产管理（生产计划、生产任务、生产报工、工单管理）
- 质量管理（质检任务、质检记录、质检标准）
- 仓库管理（库存管理、物料管理、入库管理、出库管理）
- 设备管理（设备台账、设备维修、设备维护）
- 考勤管理（考勤打卡、请假管理）
- 财务看板（财务统计、报表展示）
- 系统管理（用户管理、角色管理、部门管理）

### 2.2 技术范围
- 后端：Spring Boot 3.x + Java 17 + MyBatis-Plus
- 前端：Vue 3 + TypeScript + Vite + TailwindCSS
- 数据库：MySQL 8.0+
- 缓存：Redis 7.0+
- 移动端：微信小程序

### 2.3 排除范围
- 与ERP系统的集成（后续版本实现）
- 与WMS系统的集成（后续版本实现）
- 移动端APP开发（当前仅开发微信小程序）

## 3. 技术方案

### 3.1 架构设计

### 3.4 接口设计

#### 3.4.1 认证接口

| API路径 | 方法 | 功能 |
|---------|------|------|
| /api/auth/login | POST | 用户登录 |
| /api/auth/logout | POST | 用户退出 |
| /api/auth/info | GET | 获取用户信息 |

**登录请求参数**：
```json
{
  "userCode": "string (工号)",
  "password": "string (密码)"
}
```

**登录响应参数**：
```json
{
  "code": "int (状态码)",
  "message": "string (消息)",
  "data": {
    "id": "int (用户ID)",
    "userCode": "string (工号)",
    "realName": "string (真实姓名)",
    "roleName": "string (角色名称)",
    "deptName": "string (部门名称)"
  }
}
```
