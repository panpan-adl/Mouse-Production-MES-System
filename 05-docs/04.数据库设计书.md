# 鼠标制造执行系统 - 数据库设计书

## 1. 引言

### 1.1 编写目的
本数据库设计书旨在详细描述鼠标制造执行系统（Mouse MES）的数据库结构、表设计、字段定义和约束条件，为开发人员提供明确的数据库开发指南。

### 1.2 设计原则
- 遵循第三范式（3NF）
- 主键使用自增ID
- 外键约束确保数据完整性
- 使用软删除而非物理删除
- 统一的时间字段命名规范

## 2. 数据库环境

### 2.1 数据库选型
- **数据库类型**：MySQL 8.0+
- **字符集**：UTF-8
- **排序规则**：utf8mb4_unicode_ci

### 2.2 连接配置
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/mouse_mes?useUnicode=true&characterEncoding=utf-8&serverTimezone=GMT%2b8
    username: root
    password: <DB_PASSWORD>
    driver-class-name: com.mysql.cj.jdbc.Driver
```

## 5. 索引设计

### 5.1 主键索引
所有表的id字段为主键索引，自动创建。

### 5.2 唯一索引

| 表名 | 字段 | 索引名 |
|------|------|--------|
| t_user | user_code | uk_user_code |
| t_user | username | uk_username |
| t_role | role_name | uk_role_name |
| t_order | order_no | uk_order_no |
| t_production_order | po_no | uk_po_no |
| t_purchase_order | po_no | uk_pur_po_no |

### 5.3 普通索引

| 表名 | 字段 | 索引名 | 用途 |
|------|------|--------|------|
| t_order | order_status | idx_order_status | 按状态筛选订单 |
