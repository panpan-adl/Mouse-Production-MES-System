大模型 API 本地配置

1. 用记事本打开本目录的 knowledge.local.json。
2. 找到 "apiKey": ""，把 API Key 粘贴到两个双引号之间，然后保存。
   示例格式："apiKey": "这里替换成你的完整密钥"
3. 地址和模型名称已填好。embeddingApiKey 留空会使用同一个密钥。
4. 回到项目根目录，双击“启动知识图谱.cmd”，以后启动会自动读取配置。
   也可以告诉我“配置填好了”，我会直接使用本地配置继续启动和联调。

请保留英文双引号、逗号和大括号，不要把示例文字当作密钥填写。
配置改变后，需要重新启动后端才能生效；旧终端已有的环境变量优先于文件。

knowledge.local.json 是明文的本机私密配置，已排除 Git，不会正常提交到 GitHub。
不要把这个文件发给同学或放进交接压缩包；共享时使用空白 knowledge.example.json。
若该文件不存在，复制 knowledge.example.json 并改名 knowledge.local.json 即可。
聊天模型和嵌入模型都需要在火山方舟开通使用权限。
